# Web3 Smart Contract Forensics

Evidence-first research catalog of real-world Web3 smart-contract bugs and Critical security findings.

## Scope

Smart-contract focused. The primary collection is Critical findings from public audit and responsible-disclosure sources.

Record types:
- audit_finding
- bugfix_review
- incident

Severity is never inferred from a bounty amount.

## Research model

Finding -> Preconditions -> Reachability -> Exploitability -> Impact -> Evidence -> Root Cause -> Remediation -> Reproducibility

## Sources

Smart Contract VulnDB, Immunefi Web3 Security Library, FORGE-Curated, and OWASP Smart Contract Security.

## Data principles

Public evidence only. Source provenance is preserved.
Case confidence is explicit.
Unknown fields remain unknown.
Bounty values are case-specific only when publicly documented.
Audit findings are not silently presented as bounty reports.

## Safety

No secrets, private reports, signing material, or live-target exploit instructions.

Status: active foundation for a continuously expanding smart-contract security corpus.
