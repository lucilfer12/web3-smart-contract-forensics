# Sources

This project uses public sources and keeps provenance explicit.

## Smart Contract VulnDB
Public smart-contract vulnerability database with structured finding metadata aggregated from public audit material.
- https://github.com/tintinweb/smart-contract-vulndb

## Immunefi Web3 Security Library
Public Web3 security knowledge base and bug-fix reviews.
- https://github.com/immunefi-team/Web3-Security-Library

## FORGE-Curated
Curated public smart-contract security dataset useful for cross-checking recent findings.
- https://github.com/shenyimings/FORGE-Curated

## OWASP Smart Contract Security
Taxonomy and defensive guidance for smart-contract weaknesses.
- https://scs.owasp.org/

Source data is not copied wholesale into this repository. We retain normalized metadata and public links.
